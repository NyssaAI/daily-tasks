# UC-00.04.01 Discover Available Communication Connections and Configure Initial Lookback Window

## Actor

Individual user setting up Daily Tasks or updating their email and chat integration preferences inside an AI assistant environment.

## Goal

See which email and chat connections are already available in the assistant environment, choose which connection(s) to use for daily planning, and configure the maximum number of days to pull on the first run (defaulting to 7 days).

## Starting Context

The user is running Daily Tasks inside an AI assistant environment (where email or chat may already be connected) and is either completing initial setup ([UC-00.01.01](../f-00.01/uc-00.01.01-setup-workspace-and-templates.md)) or asking to configure or change their communication sources.

## Entry Route

The user runs the setup workflow for the first time, or asks the assistant to configure, review, or update email or chat connections and lookback settings.

## Trigger

Setup reaches the communication sources step, or the user explicitly requests communication source configuration.

## Process

```text
User selects available communication connections and initial lookback window
+-- Starting context: User is in an assistant environment with zero or more connected email/chat integrations
+-- Entry route: User invokes setup or requests communication connection changes
+-- Trigger: Setup inspects available communication sources
+-- Step 1: Assistant checks what email and chat connections are already available
|   +-- Existing assistant connection(s) detected: Assistant lists the ready-to-use connections alongside standalone options
|   \-- No existing assistant connections detected: Assistant reports none found and offers standalone read-only setup or skipping
+-- Step 2: Assistant asks the user which communication connection(s) they want to use
|   +-- User selects an existing assistant connection: Assistant records the existing connection for read-only planning use
|   +-- User selects a standalone read-only connection: Assistant transitions to standalone read-only authorization (UC-00.03.01)
|   \-- User chooses not to connect email or chat: Assistant leaves communication ingestion disabled without blocking planning
+-- Step 3: Assistant prompts for the initial pull lookback window (defaulting to 7 days)
|   +-- User accepts the default: Assistant sets the initial lookback limit to 7 days
|   +-- User specifies a custom number of days: Assistant validates and sets the custom lookback limit
|   \-- User supplies an invalid lookback value (zero or negative): Assistant explains the valid range and asks again
+-- Step 4: Assistant saves the selected connection mode and initial lookback preference
\-- Success: Communication connection choice and first-pull lookback window are saved for daily planning
```

## Step Details

### Step 1: Assistant checks what email and chat connections are already available

Rather than assuming the user must configure a new standalone connector, the assistant first checks whether the host assistant environment already provides access to the user's email or chat, and checks whether any standalone read-only credentials are already configured.

### Step 3: Assistant prompts for the initial pull lookback window (defaulting to 7 days)

The initial lookback window applies only to the very first pull for a communication source when no saved checkpoint exists yet. By default, the first pull is capped at no more than 7 days so the user is not flooded with old messages. Once a checkpoint is saved, subsequent pulls always start from that checkpoint.

## Success

The user's chosen communication connection mode (existing assistant connection, standalone connection, or disabled) and initial lookback window (7 days by default or the user's custom day count) are saved in their profile and confirmed.

## Failure Cases

- Selected assistant connection is unresponsive or lacks read permission: Assistant informs the user that the connection could not read messages and offers to re-check the connection, switch to a standalone connection, or proceed without it.
- Invalid lookback day count (such as zero, negative, or non-numeric input): Assistant explains that the initial lookback must be a positive number of days (defaulting to 7) and prompts for a valid choice without saving corrupt settings.
