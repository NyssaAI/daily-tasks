# Daily Tasks Ubiquitous Language Glossary

Authoritative bounded-context lexicon for `daily-tasks` (`REPO-GOVERNANCE`, `ARCH-NAME`). Domain concepts and macro-flows live in [`docs/concepts/`](concepts/) and versioned JSON contracts in [`docs/specs/`](specs/).

## 1. Canonical 5-Root Model & Packaging

| **Canonical Term** | `CodeSymbol` / JSON Key | Banned Synonyms | Definition |
| :--- | :--- | :--- | :--- |
| **`user_home`** | `user_home` / `userHome` | `config_dir` (when referring to `~`), `<user-home>` | User OS home directory (`~`). Owns `~/.nyssa-ai/config-manifest.json` and user-level `NyssaAI.Configuration` namespace files (`~/.nyssa-ai/daily-tasks/config.json`, with read-only legacy fallback to `profile.json`). Configuration precedence #1. |
| **`repo_root`** | `repo_root` / `repoRoot` | `project_root`, `<project-root>`, `<target-repo>`, `targetRoot` | Git software repository root. Owns `AGENTS.md`, `docs/GLOSSARY.md`, `src/`, `test/`, single root `.temp/`, and optional repo-scoped config `<repo_root>/.nyssa-ai/daily-tasks/config.json`. Configuration precedence #2. |
| **`vault_root`** | `vault_root` / `vaultRoot` / `defaultVaultRoot` | `Workspace`, `workspace_root`, `workspaceRoot`, `defaultWorkspaceRoot`, `VaultRepo`, `ProjectWorkspace`, `RepoDir` | User or shared PARA/non-PARA knowledge & work-record vault. Default folder mappings are `1-projects` (`projectsRoot`) and `2-areas/daily-plans` (`dailyPlansRelative`). Contains zero `.nyssa-ai/` secrets or machine-local runtime state, and rejects agent persona runtime roots (`SOUL.md` + `IDENTITY.md`). |
| **`runtime_root`** | `runtime_root` / `runtimeRoot` / `resolve_runtime_root` | `state_root`, `${PLUGIN_DATA}`, `workspace_root`, `working workspace root`, `agent persona workspace` | Active agent or process execution and mutable state directory, resolved in order: (1) `--runtime-root` -> (2) `NYSSA_RUNTIME_ROOT` (routing `SOUL.md` + `IDENTITY.md` roots to `.nyssa-ai/daily-tasks/runtime`) -> (3) `<cwd>/.nyssa-ai/daily-tasks/runtime` when `cwd` contains `SOUL.md` + `IDENTITY.md` (`is_agent_runtime_root`) -> (4) configured `runtimeRoot`, `<repo_root>/.nyssa-ai/daily-tasks/runtime/`, or default `~/.nyssa-ai/daily-tasks/runtime/`. Owns `fetch-cursors.json`, `suggestions.json`, `decision-log.json`, `sessions/`, opt-in `usage/events.jsonl`, `.venv/`, and runtime `.temp/`. |
| **`plugin_root`** | `plugin_root` / `pluginRoot` / `PLUGIN_ROOT` | `bundle` | Read-only installed or source plugin directory (`plugin.json`, `skills/`, `src/`, `scripts/`). Never receives user state, `.nyssa-ai/` runtime writes, or `.temp/` output at runtime. |
| **`harness-adapter`** | `harness-adapters/<harness>/` | `Host Harness`, `Host Adapter`, `Runtime Shim` | Host-facing descriptors and registration glue (`harness-adapters/hermes/`, `.claude-plugin/`, `.codex-plugin/`, `.cursor-plugin/`, `.mcp.json`, `mcp.json`) that allow an AI harness to discover and load the plugin. Unrelated to infrastructure implementations inside `src/`. |

## 2. Work Records, Planning & Collaborator Contracts

| **Canonical Term** | `CodeSymbol` | Banned Synonyms | Definition |
| :--- | :--- | :--- | :--- |
| **Record Kind** | `RecordKind` (`record_kind`) | `ItemType`, `_RecordType`, `*Type` | Canonical discriminator (`project`, `milestone`, `task`, `blocker`, `daily-plan`) across all domain records, plan entries, suggestions, operations, and changes. |
| **Project** | `Project`, `ProjectState` | `Initiative`, `Epic` | Accepted outcome-oriented effort (`1-projects/YYYY.MM.DD-<slug>/project-index.md`) governed by frontmatter `state`. |
| **Milestone** | `Milestone`, `MilestoneState` | `Sprint`, `Phase` | Concrete delivery checkpoint inside a `Project` (`mN-<slug>/mN-<slug>.md`) with embedded `DodItem` criteria. |
| **Task** | `Task`, `TaskState`, `DodItem` | `Todo`, `Ticket`, `Issue`, `task-state` | Accepted unit of work (`tN-<slug>.md`) governed by frontmatter `state` and stable `DodItem` checklist IDs. |
| **External Blocker** | `Blocker`, `BlockerState` | `Impediment`, `DependencyIssue` | Condition outside direct execution control (`blockers/bN-<slug>.md`) blocking tasks or milestones. |
| **Definition of Done (DoD)** | `DodItem`, `DodProgress` | `Acceptance criteria file`, `DoD document` | Checklist items embedded under `## Definition of Done` inside a `Milestone` or `Task` record. |
| **Daily Plan & Rollover** | `DailyPlan`, `DailyPlanDocument`, `Rollover` | `Schedule`, `TimeboxPlan`, `Agenda`, `Reschedule` | Explicit selection of accepted tasks and blocker follow-ups for a local calendar date (`2-areas/daily-plans/YYYY.MM.DD-daily-plan.md`), with once-per-day carry-forward (`↺`) and zero time-fitting. |
| **Planning Session** | `PlanningSession`, `PlanningTools`, `PlanningToolsDispatcher`, `PlanningDispatcher` | `PlanningToolsProtocol`, `PlanningSessionPort`, `CheckinWizard`, `SessionManager`, `Daily dashboard` | Stateful 3-screen deterministic adjudication workflow (`s1` Triage -> `s2` Plan -> `s3` Confirm) exposed over MCP. |
| **Suggestion** | `Suggestion`, `Suggestions`, `SuggestionKind`, `SuggestionsRepository`, `SuggestionsRepositoryJson` | `AutoUpdate`, `DraftMutation`, `JsonSuggestionsAdapter` | Deterministic candidate state change matched from communication messages, requiring explicit user verdict (`accept`, `edit`, `reject`) and persisted in `<runtime_root>/suggestions.json`. |
| **Decision Log** | `DecisionLog`, `DecisionLogEntry`, `DecisionLogger`, `DecisionLogStoreJson` | `AuditTrail`, `HistoryLog` | Append-only record of user verdicts and planning operations persisted in `<runtime_root>/decision-log.json`. |
| **Record Change & File Store** | `RecordChange`, `FileStore`, `FileStoreLocal` | `Patch`, `FileMutation`, `LocalFileStore`, `MarkdownFileStore` | Optimistically concurrency-checked (`expected_hash`) non-destructive record edit staged in memory and persisted via role-named `FileStore` (`FileStoreLocal`) only on `confirm_plan(confirmed=True)`. |
| **Project & Daily Plan Repositories** | `ProjectPlanRepository`, `ProjectPlanRepositoryMarkdown`, `DailyPlanRepository`, `DailyPlanRepositoryMarkdown` | `ProjectPlanPort`, `DailyPlanPort`, `MarkdownProjectPlanAdapter`, `MarkdownDailyPlanAdapter`, `*SourceRead` | Consumer-owned role-named read contracts in `core/records/` and entity-first Markdown implementations in `records/`. |
| **Communication Client** | `CommunicationMessage`, `CommunicationClient`, `CommunicationClientGmail`, `CommunicationClientSlack`, `CommunicationMultiplexer` | `CommunicationPort`, `GmailConnector`, `SlackConnector`, `GmailSource`, `SlackSource` | Role-named read-only communication contract in `core/communications/` and entity-first Gmail/Slack implementations in `communications/`. |
| **Fetch Cursor** | `FetchCursor`, `FetchCursors`, `CursorStore`, `CursorStoreJson` | `SyncToken`, `WatermarkFile` | Per-source high-water mark (`since`, `last_external_id`) persisted in `<runtime_root>/fetch-cursors.json` after confirmed sessions. |
| **Secret String** | `SecretString`, `SecretResolver`, `SecretCaptureService` | `PlainToken`, `RawSecret` | Redacting in-memory credential wrapper that reveals plaintext only via `.reveal()` at outbound I/O boundaries. |
