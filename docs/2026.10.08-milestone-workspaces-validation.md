# Milestone workspaces validation

The 0.3.2 update implements the accepted hierarchy: a matching numbered milestone
folder/file, sibling numbered task files, and flat inputs/outputs holding areas.
Milestones own milestone DoD; tasks own requirements and task DoD. Existing records
remain readable until a skill-owned, explicitly requested migration.
